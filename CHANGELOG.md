# Changelog

## Stage 5 - Chrome fix, App Center, smooth / no lag (this release)
New
- **App Center** (top bar > Apps): install / remove catalog apps with progress; paste a Windows setup `.exe` / `.msi` link and it is downloaded and run in Wine. `backend/abix_apps.py`, `backend/apps-catalog.json`, `frontend/apps.js`, API `/api/apps*`. SSRF-safe downloader.
- `abix-xvnc` (tuned Xtigervnc start), `abix-smooth` (one-command no-lag mode), Turbo speed preset, `ABIX_FPS`, `ABIX_EXTRA_APT`, `ABIX_APPS_RESTORE`, `ABIX_MAX_DOWNLOAD_MB`.
- `abix-fix-apps` + apt hook: Chrome / Edge / VS Code Start-menu entries now start in the container (`--no-sandbox`).
- Chrome / Edge managed policies, stale-lock cleanup, Firefox fallback when Chrome is not installed.
Changed
- Default speed is Smooth (quality 5 / compression 1). Brightness filter only when below 100 %. Nginx `/desktop/` unbuffered + keepalive, noVNC files cached. Compose defaults 3 CPUs / 4 GB / 1024 pids. Image tag `abix/cloud-desktop:v5`.
- Chrome build step: 5 download retries, amd64 check, binary verified.
Tests: +18 backend/App Center unit tests, UI test +12 checks, 10 new `S5` smoke checks (smoke not run here).
Not verified: Docker build, real Chrome/apt/Wine/HTTPS downloads, VNC options on a real server.

- Click sounds (UI + touchpad taps), Speed presets (Smooth/Balanced/Sharp), eased animations, drag-and-drop upload, gzip + tcp_nodelay.
- `docker-compose.public.yml` + `deployment/nginx-realip.conf`: share through a Cloudflare Tunnel (password still required).
- `tests/ui/test_ui.py`: real Chromium against a fake noVNC page.
Changed
- noVNC iframe now sits in `#stage`; top bar shows icons only below 1240 px; image tag `abix/cloud-desktop:v4`.
Not verified: Docker build, real noVNC input/clipboard, the tunnel.

## Stage 2 - web login, dashboard, lock, Settings, power (this release)
New
- `backend/abix_api.py`: login (PBKDF2, signed cookie), session, lock/unlock, Settings (calls `abix-ctl`), power, wallpapers. Stdlib only. 9 HTTP tests.
- `frontend/`: sign-in page, dashboard with Settings drawer (mode, animation, accent, wallpapers), lock screen, power menu with confirmation, full screen, touch-friendly bar.
- Nginx: `auth_request` guards `/desktop/` (replaces HTTP basic auth), CSP on the web app, no access log for the viewer URL.
- `deployment/set-password.sh`; `deployment/init.sh` now REPAIRS `.env` (CRLF, missing/placeholder VNC_PASSWORD), adds the login hash and session secret, and reuses your Stage 1 password.
- `tests/smoke.sh`: 24 Stage 2 checks (login, 401/403 gates, lock, settings, secrets hidden from user `abix`).
Fixed (Stage 1)
- Whisker menu: the package is called `xfce4-whiskermenu-plugin` (Stage 1 asked for a name that does not exist). Installed from apt; the source build is only a fallback and now finds real tags and supports cmake and meson.
- `VNC_PASSWORD is missing` error: `init.sh` repairs the `.env`.
Changed
- Image tag `abix/cloud-desktop:v2`. nginx mounts `./frontend` instead of `deployment/htpasswd` (the file is left in place, unused).
Not touched: `abix-home` volume, certificates, Stage 1 desktop look.
Not built: terminal and file manager (Stage 3), multi-user (Stage 4), idle auto-lock, 2FA.

## Stage 1 - Windows-11-style desktop (written; real-desktop tests still to be run by you)
New
- Centered-style bottom taskbar (Start, Search, pinned apps, window buttons, tray, clock, show-desktop), generated by `abix-ctl seed`.
- Start menu = Whisker menu (Search, Favorites=pinned, Recently used, All apps, Sign out). Fallback to Xfce Applications menu if Whisker is not installable.
- Light / Dark mode, accent colour, rounded-corner CSS, Papirus icons, DMZ cursor, Inter font (each with a fallback).
- Fluent GTK theme is tried at build time (optional); Arc is the guaranteed fallback.
- Animation level Off / Light / Full via picom (xrender); honest fallback to Xfce compositor; real result in `abix-ctl status`.
- Window snapping, 4 virtual desktops, Alt+Tab, Windows-style title-bar buttons on the right.
- 6 original wallpapers, Abix Start icon, Personalization window, desktop icons, Windows-Terminal-like terminal colours.
- `docker/abix/abix-ctl` = single control tool (Stage 2 web Settings will call it).
- tests: `tests/unit/test_abix_ctl.sh` (fake-command logic test), 19 new checks in `tests/smoke.sh`.
Changed
- `docker/supervisord.conf`: Xfce now starts through `abix-session-start` (same steps as before + seed).
- `docker/entrypoint.sh`: desktop icon copying moved into `abix-ctl seed`.
- `docker-compose.yml`: nginx bind mounts use `create_host_path: false` (missing file = clear error, never a directory); new optional env vars.
- `deployment/init.sh`: removes a wrongly created EMPTY directory in place of a file; appends new optional keys to an existing `.env` (never changes your values).
- `xfce4-whisker-menu-plugin` is no longer a hard requirement of the image build.
Not touched: `.env` values, `deployment/htpasswd`, `deployment/certs`, `deployment/first-login.txt`, the `abix-home` volume data, VNC password logic.
Rollback: see documentation/STAGE1.md.
